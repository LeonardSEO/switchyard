# @vepando/switchyard-opencode

This package has moved to [`@vepando/switchyard`](https://www.npmjs.com/package/@vepando/switchyard).

Install the unified package directly:

```bash
opencode plugin @vepando/switchyard
```

Version `0.1.4` remains only as a compatibility bridge for existing OpenCode configurations. New projects should not depend on this package.
